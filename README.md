# Smart Service Operations Optimizer

## Project Overview

The Smart Service Operations Optimizer is a Java-based application developed for the **DCIT 204/308 Data Structures and Algorithms** project. The system simulates service operations within a university campus by managing service requests, resources, and route planning using custom data structures and algorithms.

## Technologies Used

* Java
* Gradle
* PostgreSQL
* JDBC
* Git & GitHub
* JUnit (for testing)

## Installation

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Ensure Java 21 (or your team's chosen JDK) is installed.
4. Allow Gradle to download the required dependencies.
5. Configure the PostgreSQL database if required.

## How to Run the Project

1. Open the project in IntelliJ IDEA.
2. Navigate to `Main.java`.
3. Run the `main()` method to start the application.
